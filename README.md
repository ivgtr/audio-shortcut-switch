# Earbuds PC Switch

Bluetooth イヤホンを、デスクトップのショートカットからワンクリックで使い分けるアプリです。機器ごとにショートカットを作成でき、クリックするとその機器に接続して Stereo 再生出力を Windows の既定に設定します。毎回 Bluetooth とサウンドの設定画面を開く必要がありません。

[Windows 10/11 x64 版をダウンロード](https://github.com/ivgtr/earbuds-pc-switch/releases/latest)

最初に Windows でイヤホンをペアリングし、ZIP を展開して `EarbudsPC.exe` を起動します。機器を選んで「作成」を押すと、デスクトップにショートカットができます。以後は使いたい機器のショートカットをクリックするだけです。接続は作成時ではなく、クリック時に行います。

初めて使う機器で Stereo 出力が見つからない場合は、イヤホンの電源を入れ、「接続確認」で一度接続してから作成してください。
