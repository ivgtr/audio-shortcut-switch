# Earbuds PC Switch

Bluetooth イヤホンを、デスクトップのショートカットからワンクリックで切り替える Windows アプリです。機器ごとにショートカットを作成でき、クリックするとその機器に接続して Stereo 再生出力を Windows の既定に設定します。毎回設定画面を開く必要がありません。

[Windows 10/11 x64 用 ZIP をダウンロード](https://github.com/ivgtr/earbuds-pc-switch/releases/latest)

## 使い方

1. Windows でイヤホンをペアリングし、ZIP を書き込み可能な場所に展開します。
2. `EarbudsPC.exe` で機器とショートカット名を選び、「作成」を押します。デスクトップにショートカットができます。
3. 使いたいイヤホンのショートカットをクリックします。接続と既定の Stereo 出力への切り替えが自動で行われます。

ショートカットの作成時には接続しません。初めて使う機器で Stereo 出力が見つからない場合は、イヤホンの電源を入れ、「接続確認」で一度接続してから作成してください。「接続確認」は既定の出力を変更しません。

## 補足

- 切り替えるのは通常の再生用出力です。通話用出力は変更しません。
- アプリのフォルダーを移動した場合は、ショートカットを作り直してください。
- 成功時は画面を出さず、失敗時はエラーを表示して `logs/switch.log` に記録します。
